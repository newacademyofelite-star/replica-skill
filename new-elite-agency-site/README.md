# New Elite Academy — site e-learning

Site vitrine + espace étudiant de New Elite Agency, en un seul fichier `index.html` (HTML, CSS et JavaScript, sans dépendance).

- **Partie publique** : accueil (monogramme NE sur fond soie, devise), 5 formations, à propos et méthode, formulaire d'inscription, pied de page noir.
- **Espace étudiant** (`#espace`) : connexion, tableau de bord, mes formations, bibliothèque d'e-books avec lecteur, profil.

Ouvrir `index.html` dans un navigateur suffit. Compte de démonstration : `etudiant@newelite.agency` / `elite2026`.

À brancher pour la mise en production : une vraie authentification et un envoi du formulaire (la connexion et la progression sont simulées dans le navigateur via `localStorage`).
